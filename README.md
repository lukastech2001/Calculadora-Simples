# Calculadora Simples em C++

Projeto desenvolvido em C++ com o objetivo de praticar lógica de programação e operações matemáticas.
foi desenvolvido para calcular operações básicas de matemática e simular uma calculadora simples.

## Operações
- Soma
- Subtração
- Multiplicação
- Divisão
- Porcentagem

## Conceitos praticados
- Variáveis
- Estruturas condicionais
- Switch case
- if/Else
- Estruturas de repetição
- while principalmente
- Operadores matemáticos
- Entrada e saída de dados
